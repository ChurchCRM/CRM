# ChurchCRM

ChurchCRM helps churches organize people and families, groups, events, attendance, giving, volunteers, and reports in one place.

**Free. No subscription. Your data is yours.**

ChurchCRM is open-source and self-hosted, so a church can choose where its information runs and how it is managed.

## Try it or install it

See the real product before you decide:

- **[Try the live demo](https://churchcrm.io/demo.html?utm_source=github&utm_medium=referral&utm_campaign=github_content&utm_content=crm_readme_demo)** — Softaculous creates a private, temporary ChurchCRM instance for you. It expires automatically; use fictional data only.

ChurchCRM supports real church workflows, including:

**People & families → Groups → Events & attendance → Giving & financial tracking → Volunteers → Reports**
