# /locale-translate

Translate missing ChurchCRM UI terms for one or all locales.

**Arguments:** `--list`, `--locale <code>`, or `--all`

Follow the agent rules in [the Locale Translation skill](../../.agents/skills/churchcrm/locale-translation-workflow.md).
The [locale pipeline](../../docs/maintainers/locale-pipeline.md) describes branches, validation and delivery.
