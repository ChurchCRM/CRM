# Social release handoff

Use this card when a maintainer requests release marketing. A release does not
require a post on every platform: select useful campaign moments and approved
channels rather than imposing a fixed posting or hashtag quota.

## Owner and inputs

Follow [the AI operating model](../../../docs/contributing/ai-operating-model.md).
ChatGPT owns marketing/SEO drafts; Grok Bot supplies technical/release clarification.
Muse owns non-Discord community operations. NanoClaw handles Discord support and
opening issues from Discord only; it is not a marketing writer or scheduler.

Prepare one evidence packet:

- Published stable release URL/tag and linked implementation evidence.
- Audience, church outcome, limitations or upgrade/security actions.
- Verified destination readiness: release/upgrade, public demo and easy new-install
  availability are separate facts; do not imply all are ready at once.
- Current authentic captures from the visuals CDN, official branding and alt text.
- Requested channels, exact CTA/destinations and existing campaign context.

Read the owning marketing repository's current social-post and campaign-launch
cards for writing and review. Do not copy its strategy or recreate its rulebook here.
Use the approved surface voice, concrete benefits and verified claims; do not
invent savings, testimonials, support promises, product screens or logos.

## Draft and validate

Write natively for each selected channel. Verify its current constraints rather
than hardcoding platform folklore. Use relevant hashtags only when useful, not
mandatory tag blocks. Security/operational urgency must follow the verified advisory.

Run link/UTM, character-count, asset-dimension and file checks deterministically.
Return only requested copy/assets with evidence, destinations and any unresolved
readiness question. Do not create a second editable published-content archive.

## Approval

Present one final package of exact copy, assets and destinations for approval.
A draft or role assignment does not authorize posting, scheduling or outreach.
Use only an explicitly authorized publishing path; material changes return to approval.
