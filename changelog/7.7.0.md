# 🌸 ChurchCRM 7.7.0 — The "Member Care & System Reliability" Release

**Release Date**: September 18, 2026
**Theme**: Deactivation & Deceased Tracking, Reliable Language Switching, and Mobile Fixes

**Version 7.7.0** introduces essential new member lifecycle tools, expands financial reporting precision, and resolves critical day-to-day usability issues across navigation, localization, and mobile views. 

---

## ✨ Exciting New Features

### 👤 Individual Deactivation & Reactivation
Managing member statuses is now much more flexible for administrative staff.
* **Archive Individual Records:** You can now deactivate and reactivate individual person records directly—matching our existing family deactivation tool—allowing you to archive individuals without deleting their history.

### 🕊️ System-Wide Deceased Tracking
Handling sensitive member records is now dignified, consistent, and central.
* **Dedicated Status & Date:** A system-wide "Deceased" flag with an optional date field lets you mark a person's record once and have it reflected accurately across the entire system, eliminating ad-hoc workarounds.

### 🔒 Mandatory 2FA Grace Period
Securing your church's database is smoother for new team members.
* **Configurable Setup Window:** New users and administrators can now be given a configurable grace period to set up Two-Factor Authentication (2FA) upon onboarding, preventing immediate account lockouts.

---

## 🛠️ Enhancements & Improvements

### 💰 Fiscal Year Financial Scoping
* **Consistent Financial Reporting:** Finance reports now correctly scope data by fiscal year across all finance tables and generated reports.

### 🌐 Localization & Language Selection
* **Reliable Language Switching:** Fixed a critical issue where selecting a non-English language would silently revert back to English.
* **Complete Dropdown Lists:** Resolved missing country and state dropdown options across all forms, including the main Localization setup page.
* **UI Copy & Pluralization Polish:** Fixed translated text glitches that displayed raw system codes or awkward plural formats (e.g., "1 upload(s)").

### 📱 Mobile & Interface Polish
* **Mobile Event Action Footer:** Fixed the event action menu layout so buttons and options no longer overflow or get cut off on phone screens.
* **Icon & Color Corrections:** Restored missing icons across pages and ensured system error messages display in clear red/danger notification toasts.
* **Settings Save Button:** Fixed an issue where the Settings panel "Save" button remained disabled after saving once, allowing staff to save multiple changes in one session.

### 📍 Mapping & Geocoding Fixes
* **Numbered Street Support:** Address geocoding now handles numbered streets (e.g., "42nd St") properly, placing map pins accurately.
* **Bulk Re-Geocoding Restored:** The "Update All Family Coordinates" bulk action is fully restored and functional.

### 🔄 Outreach & System Recoveries
* **Automated Birthday Email Recovery:** Birthday email queues now automatically recover if a previous run was interrupted, preventing background sending tasks from getting permanently blocked.
* **Database Emoji & Special Character Support:** Upgraded database columns so special characters and emojis in event names and notes save smoothly without errors.

### ⚙️ Administration & Ongoing Platform Safety
As with every release, we continually work behind the scenes to keep your software safe, stable, and secure.
* **Database & Subdirectory Stability:** Resolved installation and upgrade SQL compatibility issues for MariaDB environments, standardized username lengths across tables, and fixed AJAX routing for installations running in subdirectories.
* **Continuous Protections:** Applied targeted calendar permission guards, public link privacy scopes, and input protections across forms to ensure your church's workspace remains protected and reliable.
