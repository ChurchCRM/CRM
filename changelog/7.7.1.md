# 🏷️ ChurchCRM 7.7.1: The "Mailing Labels & Fresh Look" Release

**Release Date**: September 27, 2026
**Theme**: Cart Mailing Labels, Refreshed Branding, Clearer Translations, Smoother Admin Settings

Getting a mailing out shouldn't mean hunting for addresses. In 7.7.1 you can print labels straight from the Cart again, and every household gets its full address. ChurchCRM also has a fresh look, with the current logo on every sign-in screen and in the sidebar. A handful of fixes make reports, member search and admin settings work the way staff expect.

---

## ✨ Exciting New Features

### 🏷️ Mailing Labels from the Cart
Printing labels for a mailing is back in the Cart, with all the options in one place.
* **Labels Button:** A new **Labels** button in the Cart's functions bar opens the label options in one dialog: individuals or by family, bulk-mail presort, "to the parents of", skip incomplete addresses, label type, font, size, starting row and column, and PDF or CSV.
* **Remembers Your Choices:** The dialog fills in the options you used last time, and the finished labels open in a new tab.
* **Family Addresses Used Automatically:** If someone's address is stored only on their family record, their label now uses the family address instead of printing blank. Each label uses the person's own address when they have one, otherwise the family's, and never mixes the two.

### 🎨 A Fresh New Look
ChurchCRM now carries its current logo and brand everywhere you see it.
* **Current ChurchCRM Logo:** The current ChurchCRM logo now appears on:
  * The login, setup, password reset, two-factor, forced password change and limited-access screens.
  * The sidebar, in both light and dark themes.
  * Emails, when your church hasn't uploaded its own logo.
* **New Browser Tab Icon:** The icon on your browser tab now matches the current brand symbol.

---

## 🛠️ Enhancements & Improvements

### 💰 Giving & Financial Tracking
* **Pledge Reminders Without a Fund:** **Finance → Financial Reports → Pledge Reminders** no longer fails with an error when no fund is selected. It covers every fund in the chosen fiscal year, and letters no longer show empty `()` where a fund name would go.

### 👥 Usability & Directory Enhancements
* **Consistent Member Search:** Searching for a person works the same way at event check-in (walk-ins), check-out and a group's "Add Member". The check-in list is no longer cut off inside its card or stopped at 50 results.

### 🧑‍🤝‍🧑 A Richer Demo Congregation
The optional demo data now looks and behaves more like a real church, so you can try ChurchCRM on believable records before entering your own.
* **Member Status Examples:** The demo now includes 9 inactive families, an inactive member and a deceased member, so you can see the member-status tools from 7.7.0 in action.
* **Many More Photos:** About 110 people and 13 families now have photos, up from about 45 people and 2 families.
* **More Believable Households:** Names, genders, family roles, ages and wedding dates were corrected so households read like real families.

### ⚙️ Administration & Ongoing Platform Safety
* **Church Social Media Links:** **Admin → System → Church Information** has optional fields for your church's X, YouTube, Facebook and Instagram addresses.
* **Scheduled Tasks Settings:** A new **Scheduled Tasks** tab in **Admin → System Settings** holds the settings that control when the "Scheduled tasks are not running" warning appears. That warning told you to change these settings, but until now there was no screen for them. The scheduler command in the warning is also readable now; it used to show as white text on white.
* **Clearer Error Messages:** Everyday errors such as "User not found" now say what went wrong instead of showing a generic message. Database details stay out of error messages, and connected tools get every error in the same format.
* **Demo Data and Privacy:** Loading the demo congregation during first-time setup no longer changes your usage-sharing (telemetry) setting. Full anonymous telemetry is turned on only by the deliberate forced reseed that the public demo site uses.

## 🌍 Global Language Polish
* **Complete Localization:** ChurchCRM is available in 49 languages, and the new features and updates in this release are ready for translation in all of them.
* **Natural Wording for Counts:** Messages that include a number now read correctly in every language, including those with several plural forms such as Russian, Polish, Czech and Arabic. For example, "Members copied: 12" replaces "Copied 12 members".
* **Plural Translations Reach Translators:** Words with plural forms now reach our translation service correctly, so volunteer translators can fill in every form their language needs.

## 🧰 Behind the Scenes
* **Security & Dependencies:** Updated HTML Purifier (4.19.1), Moment.js (2.31.0, which includes an upstream security fix), PostHog and js-yaml (a build tool, GHSA-2883-xcg3-v3hh), and tightened date and choice-list checks on calendar event forms.
* **Testing & Tooling:** Added and repaired automated tests for cart labels, church social links, scheduled-task settings, pledge reminders, the People Dashboard and person verification. Also hardened the GitHub Actions workflows and moved them to a pinned Ubuntu 24.04 runner.

---

## 🤝 For Contributors & AI Agents
* **Easier Onboarding:** Guidance for developers and AI coding agents is now short and points straight at the code. Agents spend fewer tokens reading instructions, and people and agents follow the same written pull request review rules (agents can draft reviews but never approve or merge).
* **Zero-Token Automation:** Wherever we can, project automation runs as plain scripts with no AI model call. That covers changelog updates, Dependabot checks and the security check on new issues. It costs nothing to run, and no AI key sits in public workflow logs.
