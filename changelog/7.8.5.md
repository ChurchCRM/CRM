# ChurchCRM 7.8.5 Release Notes

## ⚠️ Before you upgrade — database requirements

ChurchCRM requires **MySQL 8.4 or newer**, or **MariaDB 10.11 or newer**. The setup and upgrade wizard checks your database version first and stops before making any changes if your server is running something older, so an old database can never leave an upgrade half-finished.

Why the change: MySQL 8.0 and earlier, and MariaDB 10.10 and earlier, no longer receive security fixes from their vendors. The new minimums are the oldest database versions that are still security-supported. If your host still runs an older database, ask them to move your site to MySQL 8.4 or MariaDB 10.11 before upgrading — most cPanel hosts already default to MariaDB 10.11, so for many churches this is already in place.

## Member Portal and staff accounts

The retired Edit Self account mode and its database column have been removed. The 7.8.3 member sign-in upgrade removes non-admin self-service accounts before the column is dropped. Members continue to use Member Portal sign-in without a staff account; administrators and read-only staff keep their existing access.

To give someone staff editing access, grant Edit Records on their staff account. Member Portal permissions and volunteer team grants continue to control member actions in the portal.
