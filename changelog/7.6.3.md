# 🌸 ChurchCRM 7.6.3 — The "Backup Reliability & Interactive Maps" Release

**Release Date**: August 31, 2026
**Theme**: Fixed Scheduled Backups, Redesigned Congregation Maps, and High-Resolution Photos

**Version 7.6.3** delivers critical fixes to automated background tasks, introduces powerful new mapping and neighbor-finder tools, enhances member photo quality, and applies essential security and performance optimizations.

---

## ✨ Exciting New Features

### 🗺️ Redesigned Congregation Map & Neighbor Finder
We’ve completely replaced the old geographical utility tools with a modern, interactive location suite.
* **Interactive Church Map:** Enjoy a redesigned congregation map centered on your church location, complete with a clean, clickable legend.
* **Find Neighbors Tool:** Easily find families living near one another. Search by family, filter by distance radius or member classification, view exact distance and direction, and add matching results directly to your active cart in bulk.
* **Profile Mini-Maps:** Member profile pages now feature a modern address card complete with an interactive mini-map and quick direction links.

### 🖼️ Sharper, High-Resolution Profile Photos
* **Higher Clarity Displays:** Person and family profile photos are no longer capped at low resolutions. Storage and display limits have both been increased significantly for a crisp, clear look across member profiles. *(Note: To view photos in high resolution, existing images will need to be re-uploaded).*

---

## 🛠️ Enhancements & Improvements

### 💾 Important Backup & Automation Fixes
* **Scheduled Backup Repair:** Fixed an issue where automated background backups failed to run when triggered by the system. If your ministry relies on automated backup schedules, please verify your backup folder to confirm regular file creation.

### 👥 Usability & Directory Enhancements
* **Anniversary Calendar Precision:** Fixed anniversary calendar entries to display couple and family names instead of home address numbers, eliminating visual confusion and preserving privacy.
* **Flexible Date Importing:** CSV imports now correctly handle four-digit year values without defaulting to today's date. You can now also import year-only birthdates across separate Year/Month/Day columns—ideal for historical member records where only a birth year is known.
* **Pop-up Menu Stability:** Fixed visual clipping on dropdown menus within pop-up windows (including group additions, Sunday School role assignments, and event check-ins). 
* **Cart to Group Selection:** Resolved an issue where the "Empty Cart to Group" selection window closed automatically before a selection could be made.

### ⚡ Database Performance Updates
* **Faster Page Loads & Exports:** Optimized heavy database queries across key administration screens. Pages such as the Sunday School email export and missing-email reports now load noticeably faster on larger church databases (reducing export lookups from over 1,500 queries down to just 2).

### ⚙️ Administration & Ongoing Platform Safety
As with every release, we continually work behind the scenes to keep your software safe, stable, and secure.
* **Hardened File & Backup Guards:** Enforced strict file-type allowlists on image uploads and locked down upload execution permissions across web server configurations.
* **Enhanced System Security:** Applied strict content security rules, refined input sanitization across administrative settings, and updated internal security contact links.
