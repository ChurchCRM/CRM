# 🌸 ChurchCRM 7.6.4 — The "Event Dashboard & Financial Reliability" Release

**Release Date**: September 1, 2026
**Theme**: Month-Based Event Filtering, Anonymous Giving Support, and Dashboard Stability

**Version 7.6.4** brings helpful new filtering options to the Event Dashboard, expands financial flexibility for anonymous donations, fixes date-parsing glitches on member profiles, and cleans up background dashboard alerts.

---

## ✨ Exciting New Features

### 📅 Event Dashboard Month Filtering
Managing church calendars and event rosters is now even more convenient.
* **Dedicated Month Filter:** The Event Dashboard now features an interactive month filter, making it easy to focus on specific event schedules without scrolling through the full yearly roster.

---

## 🛠️ Enhancements & Improvements

### 💰 Anonymous Donations & Financial Schema Fixes
* **Flexible Anonymous Giving:** Process online and recorded guest payments seamlessly—anonymous donor transactions no longer require an associated Family record.
* **Database Schema Completeness:** Restored the missing pledge denominations table (`pledge_denominations_pdem`) in core database migrations to ensure full compatibility across pledge denomination entries.
* **Disabled Feature Optimization:** System widgets now automatically skip unnecessary Fundraiser API requests when the Fundraiser module is disabled, keeping page loads lightweight.

### 👥 Usability & Profile Fixes
* **Zero-Padded Date Saving:** Resolved an issue where leading zeros in birth month or day entries caused dates to save incorrectly on member profiles.
* **Alphabetical Waiting Lists:** Event roster waiting lists are now automatically sorted alphabetically for cleaner, fairer event tracking.
* **Actionable Report Guidance:** Improved empty-state messages on "Person by Property" and "Volunteer Opportunities" reports to give clear guidance when no matching records are found.
* **Dashboard Error Suppression:** Suppressed disruptive pop-up error dialogs on data tables when navigating dashboard widgets.

### ⚙️ Administration & Ongoing Platform Safety
As with every release, we continually work behind the scenes to keep your software safe, stable, and secure.
* **Multilingual Email Composer:** Resolved a timing conflict between language loading and the rich email editor when composing emails in non-English locales.
* **Continuous Protections:** Updated dependency libraries and refined build workflows to maintain a stable, secure workspace for your ministry.

---

## 🌍 Global Language Polish
* **Complete Localization:** The system is fully localized across 45+ supported languages for all the new features and updates in this release.
