# ChurchCRM 7.8.2 Release Notes

ChurchCRM 7.8.2 (The “Clear Access” Release) focuses on giving church staff clearer visibility into sent messages, safer sign-in processes, and simplified volunteer permissions that match daily ministry roles.

---

## ⚠️ Important Guidance Before You Upgrade

Please review these key changes before updating your system:

* **Urgent Security Update for Server PHP:** Critical security vulnerabilities (CVE-2026-109618 and CVE-2026-109619, known as "PHP2Shell") were published this week across the web. If you use official ChurchCRM Docker images, update to the newly released image running patched PHP 8.4.27. If you host ChurchCRM on your own server, ensure your server's PHP installation is updated immediately.
* **Individual vs. Family Email Addresses:** Account emails (such as password resets and lockouts) now go strictly to a person's individual email address on their profile, rather than a shared family address. If family members share an address and lack individual email entries, update their profiles (**People → [Name] → Edit**) so they do not miss personal notifications.
* **Streamlined Menu Permissions:** The generic "Menu Options" administrative permission has been retired so each permission clearly matches what a user can do:
  * *Defining/Deleting Properties:* Restricted to Administrators.
  * *Assigning Properties & Verification Reports:* Requires "Edit Records" access.
  * *Group Properties:* Requires "Manage Groups" access.
  * *Mailing Labels & Letters:* Now available to all staff users automatically.
* **Safer Password Resets:** Opening a password reset link no longer emails passwords or changes them automatically. It now directs users to a secure page where they choose a new password, preventing automated email scanners from triggering accidental resets.
* **Updated Email Subjects:** Automatic system emails (such as giving statements and birthday notices) no longer prefix the church name in the subject line, avoiding repetitive headers like *"First Church - First Church Giving Statement"*.

---

## 📧 Email History & Communication Workflows

* **Searchable Email Log:** Ministry leaders and staff can now search and filter all sent, queued, and failed messages (**People → Email** or **Admin → Email Log**).
* **Clear Delivery Status:** Instantly see why a message failed or filter by status badges (*Queued* or *Failed*).
* **Direct Recipient Links:** Easily jump to a recipient's profile directly from the email log history.
* **Sender Email History:** Users with email sending privileges can now track their own message history directly from the email composer.
* **Better Mobile Display:** Verification and system emails now wrap long links properly, preventing distorted layouts on smartphone screens.
* **Clean Email Closings:** Removing sign-off details or signers no longer leaves stray commas or blank lines at the bottom of messages.

---

## 👥 Volunteer, Staff & Administrative Usability

* **Bulk Add to Cart:** Select multiple people directly from the Person Listing page and add them to your cart in bulk for quick actions, exports, or messaging.
* **Cleaner Displays:** Action buttons like *Refresh Coordinates*, *Group Properties*, and *Verify People* now only appear for staff who have permission to use them.
* **Instant Calendar Sharing Warnings:** If calendar sharing is disabled globally, a clear warning appears immediately when trying to generate a share token.
* **Multi-Language Enhancements:** Fully updated translations across 49 supported languages, with calendar improvements for German, Czech, Korean, Farsi, Norwegian, Tajik, and Belarusian.

---

## 📍 Maps, Locations & System Safeguards

* **Bulk Coordinate Updates for Editors:** Staff with "Edit Records" access can now update map coordinates in bulk without needing full Administrator rights.
* **Resilient Map Lookups:** Map outage errors or timeouts no longer wipe existing family coordinates or record inaccurate locations, preserving data for the next update attempt.
* **Event Creation Fixes:** Fixed an issue where creating repeating events assigned to specific calendars could result in a server error.
* **Folder Install Navigation:** Fixed navigation links and buttons for ChurchCRM installations running inside site subfolders (e.g., `/churchcrm`).
